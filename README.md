# 每日法语一句 · Une phrase par jour

给爸妈用的法语入门网页。手机浏览器打开，每天一句日常法语。

- 30 句最常用场景：打招呼、咖啡馆、面包店、问路、看病、买票、天气、结账、道别
- 每句有中文翻译、近似读音、逐词讲解和一条用法小贴士
- 点整句听发音，点任何一个单词单独听，可切慢速
- 「学会了」进度存在手机本地，不上传任何数据

## 使用

打开网页即可，无需安装。建议在手机浏览器里「添加到主屏幕」。

发音用的是手机自带的法语语音，需要先装一个：

- iPhone：设置 → 辅助功能 → 朗读内容 → 声音 → 法语，下载 Thomas 或 Amélie
- 安卓：设置 → 语言 → 文字转语音 → 安装法语语音包

装好之后离线也能用。

## 改内容

全部句子在 `index.html` 顶部的 `LESSONS` 数组里，一句一个对象：

```js
{
  sceneFr:"AU CAFÉ", scene:"要一杯水",
  fr:[["J'aimerais","我想要","je（我）＋ aimerais（想要）"], ["boire","喝"], ["de","一些"], ["l'eau","水"], [".",null]],
  zh:"我想喝水。",
  approx:"热梅雷 布瓦尔 德 楼。",
  tip:"<b>j'aimerais</b> 比 <b>je veux</b> 客气得多。"
}
```

`fr` 里每一项是 `[法语词, 中文意思, 可选的语法说明]`；标点写成 `[".", null]`，不会被当成单词。

没有构建步骤，改完直接刷新。

## 说明

近似读音只是记忆拐杖。法语的小舌音 r 和鼻音（bon、vin）中文拼不出来，主要还是跟着声音模仿。
